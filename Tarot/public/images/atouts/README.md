# Illustrations des atouts

Déposez ici vos images pour personnaliser les 21 atouts et l'Excuse. Dès qu'un fichier est présent, il remplace automatiquement l'affichage par défaut (nom classique + symbole) — aucune configuration supplémentaire n'est nécessaire, il suffit de nommer les fichiers exactement comme indiqué ci-dessous et de relancer le serveur (ou simplement recharger la page).

## Noms de fichiers attendus

```
atout-1.png   (Le Bateleur)         atout-12.png  (Le Pendu)
atout-2.png   (La Papesse)          atout-13.png  (Arcane sans nom)
atout-3.png   (L'Impératrice)       atout-14.png  (Tempérance)
atout-4.png   (L'Empereur)          atout-15.png  (Le Diable)
atout-5.png   (Le Pape)             atout-16.png  (La Maison Dieu)
atout-6.png   (L'Amoureux)          atout-17.png  (L'Étoile)
atout-7.png   (Le Chariot)          atout-18.png  (La Lune)
atout-8.png   (La Justice)          atout-19.png  (Le Soleil)
atout-9.png   (L'Hermite)           atout-20.png  (Le Jugement)
atout-10.png  (La Roue de Fortune)  atout-21.png  (Le Monde)
atout-11.png  (La Force)            excuse.png    (L'Excuse / Le Mat)
```

- Formats acceptés : `.png`, `.jpg` ou `.svg` (indiquez la bonne extension dans le nom de fichier si vous n'utilisez pas `.png` — sinon adaptez `IMG_EXT` en haut de `public/client.js`).
- Format vertical conseillé, ratio proche de 2:3 (par exemple 400×600px), fond plein (pas de transparence nécessaire) : l'image remplit toute la carte, les numéros restent affichés par-dessus dans les coins.
- Tant qu'un fichier est absent, la carte correspondante s'affiche avec son nom traditionnel et un symbole par défaut — le jeu reste jouable sans aucune image.

## Où trouver des illustrations libres de droits

Les 22 arcanes majeurs du Tarot de Marseille sont un motif traditionnel du domaine public, mais les **reproductions numériques précises** (scans, gravures) peuvent avoir leurs propres droits selon l'édition et l'éditeur. Avant d'utiliser des images trouvées en ligne, vérifiez leur statut — Wikimedia Commons (catégorie « Tarot of Marseilles ») référence en général des scans de jeux anciens tombés dans le domaine public avec leur licence indiquée. Vous pouvez sinon dessiner vos propres illustrations ou en commander.
