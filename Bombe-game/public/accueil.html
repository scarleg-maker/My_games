💣 Jeu de la Bombe

Posez vos bombes, tirez vos images, évitez les pièges. Chaque groupe joue dans son propre salon : plusieurs parties peuvent se dérouler en même temps.

Créer une partie

Vous devenez l'arbitre : un salon est créé avec un code à donner aux joueurs.

Choisir mon propre code

3 à 10 lettres ou chiffres. Pratique pour retrouver le même salon (avec ses images et ses joueurs habituels) d'une fois sur l'autre.

Rejoindre une partie

Entrez le code donné par l'arbitre (ou scannez son QR code), puis choisissez votre siège.
