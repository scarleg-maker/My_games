CASINO ROYAL

Roulette Europeenne

Simulation multi-joueurs

Chaque groupe joue dans son propre salon : autant de parties separees que vous voulez, en meme temps, sans se gener.

Creer un salon

Vous devenez le maitre du jeu : un salon est cree avec un code a donner aux joueurs (ou un QR code a scanner).

Choisir mon propre code

3 a 10 lettres ou chiffres. Pratique pour retrouver le meme salon (et ses sauvegardes) d'une fois sur l'autre.

Rejoindre un salon

Entrez le code donne par le maitre du jeu, puis choisissez votre siege.
