🐷 Trou-cochon

Le jeu de dé de 2 à 6 joueurs : pose tous tes pions avant les autres, évite les cases occupées et le dernier trou !

Ouverture de ta salle de maître du jeu…

Créer une partie

Tu deviens le maître du jeu : un salon est créé avec un code à donner aux joueurs.

Choisir mon propre code

3 à 10 lettres ou chiffres. Retrouve le même salon (et tes joueurs habituels) d'une fois sur l'autre.

Rejoindre une partie

Entre le code donné par le maître du jeu, puis choisis ton siège.
