🎓 Baccalauréat

Chaque groupe joue dans son propre salon : plusieurs parties peuvent tourner en même temps.

Créer une partie

Vous devenez le maître du jeu : un salon est créé avec un code à donner aux joueurs.

Choisir mon propre code

3 à 10 lettres ou chiffres. Pratique pour retrouver facilement votre salon.

Rejoindre une partie

Entrez le code donné par le maître du jeu (ou scannez son QR code), puis choisissez votre nom.
