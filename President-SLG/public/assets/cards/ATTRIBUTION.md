# Cartes à jouer standard (mode A)

Ces visuels proviennent du projet **SVG-cards** :
https://github.com/htdebeer/SVG-cards

- Auteur original : David Bellot (http://svg-cards.sourceforge.net/)

Chaque fichier `.svg` de ce dossier est une carte extraite individuellement
depuis `svg-cards.svg` (via `rsvg-convert --export-id`), sans autre
modification du contenu graphique.
