MONOPOLY

Jusqu'à 8 joueurs, humains ou IA. Chaque groupe joue dans son propre salon.

Créer un salon

Tu deviens l'hôte : un salon est créé avec un code (et un QR code) à partager.

Choisir mon propre code

3 à 10 lettres ou chiffres. Pratique pour retrouver le même salon (et ses réglages) d'une fois sur l'autre.

Rejoindre un salon

Entre le code donné par l'hôte, puis touche ton siège.
