Puis-thème 4

Le Puissance 4 de 2 à 6 joueurs : classique, renversé, ou thématique avec des questions. Chaque groupe joue dans son propre salon.

Créer une partie

Tu deviens l'arbitre : un salon est créé avec un code à donner aux joueurs.

Choisir mon propre code

3 à 10 lettres ou chiffres. Pratique pour retrouver le même salon (et ses joueurs habituels) d'une fois sur l'autre.

Rejoindre une partie

Entre le code donné par l'arbitre, puis choisis ton siège.
