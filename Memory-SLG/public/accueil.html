🧠 Memory-SLG

Le jeu des paires avec vos propres images, de 1 à 8 joueurs. Chaque groupe joue dans son propre salon, séparé des autres.

Créer une partie

Tu deviens l'arbitre : un salon est créé avec un code à donner aux joueurs.

Choisir mon propre code

3 à 10 lettres ou chiffres. Pratique pour retrouver le même salon, avec ses images et ses joueurs, d'une fois sur l'autre.

Rejoindre une partie

Entre le code donné par l'arbitre, puis choisis ton siège.
