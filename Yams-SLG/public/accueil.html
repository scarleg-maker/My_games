🎲 Yam's

Chaque groupe joue dans son propre salon, avec sa partie séparée.

Créer une partie

Vous devenez l'arbitre : un salon est créé avec un code à donner aux joueurs.

Choisir mon propre code

3 à 10 lettres ou chiffres. Pratique pour retrouver le même salon (et ses joueurs habituels, son palmarès) d'une fois sur l'autre.

Rejoindre une partie

Entrez le code donné par l'arbitre, puis choisissez votre siège.
