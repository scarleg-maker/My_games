Duo-Master

Le jeu des associations à deux critères, de 2 à 6 joueurs. Chaque groupe joue dans son propre salon, indépendant des autres.

Créer une partie

Tu deviens l'arbitre : un salon est créé avec un code à donner aux joueurs.

Choisir mon propre code

3 à 8 lettres ou chiffres (sans 0, O, 1, I, L pour éviter les confusions). Pratique pour retrouver le même salon d'une fois sur l'autre.

Rejoindre une partie

Entre le code donné par l'arbitre, puis touche ton nom.
